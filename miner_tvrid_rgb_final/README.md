# MINER — ReID training configuration

This directory contains the released TVRID RGB implementation, extended here
with an LTCC adapter so the local clothes-changing dataset can be trained with
the MINER sampler. The active configuration is `configs/rgb.yml`; the original
TVRID-only configuration is `configs/tvrid.yml`.

## Prerequisites

- Python 3.10+, CUDA GPU
- LTCC extracted dataset under `/home/data/LTCC_ReID`
- DIFFER-initialized EVA02-Large checkpoint

```bash
pip install -r requirements.txt
```

## Setup

### Local LTCC configuration

The repository's active `configs/rgb.yml` is configured for the LTCC dataset
found under `/home/data/LTCC_ReID`. It follows the paper's DIFFER-initialized
settings and writes each run to `../logs/<YYYYMMDD_HHMMSS>/`.

Before training, place the DIFFER EVA02-L checkpoint at
`weights/differ_ltcc.pth`. If the checkpoint is available, pre-compute the
camera-conditioned MINER centroids with:

```bash
python generate_embeddings.py \
    --dataset ltcc \
    --data-root /home/data \
    --checkpoint weights/differ_ltcc.pth \
    --output weights/ltcc_embeddings_camera.json
```

Then train with:

```bash
WANDB_MODE=disabled ./run_ppu.sh python train.py --config configs/rgb.yml
```

The original TVRID configuration is retained as `configs/tvrid.yml`.

### LTCC weights

Place in `weights/`:
- `differ_ltcc.pth` — DIFFER-initialized EVA02-Large checkpoint
- `ltcc_embeddings_camera.json` — generated by the command above; it preserves
  the DIFFER camera embedding during centroid construction

### TVRID legacy setup

For the original TVRID release, use `configs/tvrid.yml`, place
`eva02_l_bio_best.pth` and `tvrid_embeddings.json` in `weights/`, and unzip the
extracted archive into `data/`:
```
data/DB_extracted/
├── train_labels.csv
├── public_test_labels.csv
├── train/
└── test_public/
```

## Reproduce

### Train

```bash
python train.py --config configs/rgb.yml
```

Produces `logs/<YYYYMMDD_HHMMSS>/best.pth`.

### LTCC evaluation

```bash
./run_ppu.sh python evaluate_ltcc.py \
    --checkpoint /home/MINER/logs/<YYYYMMDD_HHMMSS>/best.pth \
    --data-root /home/data --batch-size 32 --num-workers 2
```

The evaluator prints both standard and clothes-changing LTCC metrics.

### TVRID submission

The submission command below remains TVRID-specific:

```bash
python submit.py \
    --config configs/tvrid.yml \
    --checkpoint logs/<YYYYMMDD_HHMMSS>/best.pth \
    --output submission/
```

Produces `submission/rankings_rgb.csv`.

### Custom data location

```bash
python train.py --config configs/rgb.yml DATA.ROOT /path/to/data
python submit.py --config configs/rgb.yml --checkpoint logs/best.pth --data-root /path/to/data --output submission/
```
